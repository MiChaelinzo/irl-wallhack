# 24 RF lab status by mandate section

Written at the end of the RF lab work on branch `feat/rf-lab`, after reading the code, not from memory of what was planned. Status words:

- **Complete**: built, tested, and the section's stated goal is met within the limits listed.
- **Partial**: a useful part is built; the missing part is named.
- **Deferred**: not built. Nothing in the repository pretends otherwise.

Verification labels follow the README (VERIFIED, PARTIALLY VERIFIED, UNVERIFIED). Every propagation, throughput and reliability number is a MODEL ESTIMATE. No result has been compared with a measured survey or with real radios.
